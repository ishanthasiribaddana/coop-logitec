Phase 1: Foundation

Project setup, authentication, user management, database schema

6 Weeks
Weeks 1–6
WK 1
Project Kickoff & Environment Setup
Git repo setup (monorepo structure). Docker Compose config: WildFly 31 + MariaDB 10.6 + Redis 5.0.2. Maven parent POM with Jakarta EE 10 BOM. CI/CD pipeline (GitHub Actions). Development environment documentation.
React Project Scaffolding
AdminApp: Vite + React 18.2 + Tailwind CSS + Zustand. Project structure, routing (React Router 6), layout components. Design system: colors, typography, component library setup.
DevOps Backend Frontend PM
WK 2
Database Schema — Groups A, B, J
MariaDB schema: general_user_profile, general_role, user_role, role_permission, general_organization_profile, org_address, org_contact, tax_rate, system_configuration, audit_log. JPA @Entity classes with Hibernate mappings.
Depends: WK1 Docker
AdminApp: Auth UI
Login page, forgot password flow, OTP verification screen. Zustand auth store. Axios interceptors for JWT. Protected route wrapper.
Backend DevOps Frontend
WK 3
Authentication EJBs
JWT provider (io.jsonwebtoken 0.11.5): access + refresh tokens. BCrypt password hashing. OTP generation & validation. Auth JAX-RS endpoints: /api/auth/login, /register, /refresh, /forgot-password, /verify-otp. CORS filter config.
Depends: WK2 Schema
AdminApp: Layout & Navigation
Sidebar navigation, top bar with user menu. Breadcrumbs. Responsive layout. Toast notification system. Loading states & error boundaries.
Backend Frontend
WK 4
User Management EJBs & API
User CRUD EJBs. Role & permission management. RBAC interceptor for JAX-RS. Endpoints: /api/users (CRUD), /api/roles (CRUD), /api/permissions. Pagination, search, filtering.
Depends: WK3 Auth
AdminApp: User Management Screens
User list (data table with search, filter, pagination). Create/edit user form. Role assignment. User profile view. Password reset (admin).
Depends: WK3 Auth UI
Backend Frontend
WK 5
Organization Management EJBs & API
Organization CRUD EJBs (Vendor, Distributor, Shop). Org hierarchy & relationships. Endpoints: /api/organizations (CRUD), /api/organizations/{id}/addresses, /api/organizations/{id}/contacts. Vendor-Distributor mapping.
Depends: WK4 Users
AdminApp: Organization Screens
Organization list & detail views. Create/edit org with address & contact tabs. Vendor management. Distributor management. Shop registration. Org type filtering.
Backend Frontend
WK 6
Phase 1 Integration & Testing
End-to-end integration testing: Auth → User → Org flows. JUnit 5 unit tests for auth & user EJBs. API documentation (Swagger/OpenAPI). Bug fixes. Code review & refactoring.
AdminApp: Polish & Bug Fixes
UI polish, responsive testing. Error handling improvements. Loading states. Form validation. Cross-browser testing.
Backend Frontend QA
🏆
Milestone 1: Foundation Complete
Working auth system, user/org CRUD, RBAC, AdminApp login + management screens, Docker environment running

Phase 2: Core Operations

Product catalog, order management, inventory, mobile app (Sales Rep)

8 Weeks
Weeks 7–14
WK 7
Product & Catalog Schema + EJBs
JPA entities: product, product_category, product_image, product_price, product_unit_of_measure. Product CRUD EJBs. Category hierarchy. Endpoints: /api/products, /api/categories. Image upload (file storage).
Depends: P1 Complete
Mobile App: Project Setup
React Native project init. Navigation (React Navigation). SQLite local database setup (react-native-sqlite-storage). Offline-first architecture. Auth flow (JWT storage in SecureStore).
Backend Mobile
WK 8
Inventory Schema + EJBs
JPA entities: inventory, inventory_batch, inventory_movement, goods_received_note, grn_item. Inventory tracking EJBs. Stock level calculations. Endpoints: /api/inventory, /api/grn. Low stock alerts logic.
AdminApp: Product Catalog Screens
Product list with image grid/table toggle. Product create/edit form (multi-step: basic info, pricing, images, UOM). Category management tree view. Bulk import (CSV).
Backend Frontend
WK 9
Order Management Schema + EJBs
JPA entities: sales_order, sales_order_item, order_status_history. Order lifecycle EJBs (DRAFT → SUBMITTED → APPROVED → PROCESSING → LOADED → IN_TRANSIT → DELIVERED → COMPLETED). Endpoints: /api/orders (CRUD + status transitions).
Mobile App: Sales Rep Home & Shop Visit
Dashboard screen: today's stats, route summary. Shop list with search. GPS check-in/check-out. Shop detail view with order history & outstanding balance.
Backend Mobile
WK 10
Redis Cache Integration
Jedis client setup. Cache product catalog, pricing, stock levels. Cache invalidation strategy. Session caching. API response caching for hot endpoints.
Mobile App: Order Creation
Product browse & search (offline catalog). Category filtering. Add to cart with quantity & discount. Order review screen. Submit order (offline queue with idempotency key).
Backend Mobile
WK 11
Distributor-Shop Mapping & Pricing
distributor_shop entity & EJBs. Shop-specific pricing tiers. Credit limit management. Payment terms configuration. Endpoints: /api/distributor-shops.
AdminApp: Order Management Screens
Order list with status filters & search. Order detail view with timeline. Approve/reject workflow. Order status tracking. Bulk order operations.
Backend Frontend
WK 12
AdminApp: Inventory Screens
Inventory dashboard (stock levels by warehouse). GRN creation & management. Stock movement history. Low stock alerts list. Batch tracking view.
Mobile App: Order History & Sync
Order history list with status badges. Order detail view. Basic sync engine: push pending orders, pull catalog updates. Sync status indicator. Conflict detection.
Frontend Mobile
WK 13
Order-Inventory Integration
Order approval → inventory reservation. Stock deduction on delivery. Return → stock restoration. Inventory movement audit trail. Concurrent order handling (optimistic locking).
Mobile App: Offline Catalog & Map
Offline product catalog with images. Route map view (react-native-maps). Shop pins with visit status. GPS tracking background service.
Backend Mobile
WK 14
Phase 2 Integration & Testing
End-to-end: Order creation (mobile) → Approval (admin) → Inventory update. JUnit tests for order & inventory EJBs. Mobile app testing on Android & iOS. Performance testing (Redis cache hit rates). Bug fixes.
Demo & Stakeholder Review
Demo to TecCoop stakeholders. Feedback collection. Backlog grooming for Phase 3. Documentation update.
QA PM Backend
🏆
Milestone 2: Core Operations Live
Sales Rep mobile app (offline orders), product catalog, inventory tracking, order lifecycle, AdminApp management screens, Redis caching

Phase 3: Delivery & Logistics

Vehicle management, delivery trips, route planning, GPS tracking, delivery notes

6 Weeks
Weeks 15–20
WK 15
Vehicle & Delivery Schema + EJBs
JPA entities: vehicle, delivery_trip, delivery_trip_order, delivery_confirmation, delivery_return_item. Vehicle CRUD. Trip creation & assignment. Endpoints: /api/vehicles, /api/delivery-trips.
Depends: P2 Orders
AdminApp: Vehicle Management
Vehicle list & registration. Driver assignment. Vehicle status tracking. Maintenance schedule view.
Backend Frontend
WK 16
Route Planning Schema + EJBs
JPA entities: route_plan, route_plan_stop, gps_tracking_log. Route creation & optimization. GPS tracking endpoint. Endpoints: /api/routes, /api/gps-tracking.
AdminApp: Trip Planner & Route Planning
Trip creation wizard: select orders → assign vehicle → generate route. Route map visualization. Drag-and-drop stop reordering. Loading sheet generation.
Backend Frontend
WK 17
Voucher Module — DN & Loading Note
JPA entities: voucher, voucher_line, voucher_type, voucher_number_sequence, voucher_tax_summary. Voucher generation EJBs for Delivery Notes (DN) and Loading Notes (LN). Auto-numbering: DN-2026-00001 format.
Mobile App: Delivery Personnel — Trip View
Trip dashboard: assigned deliveries, vehicle info, progress. Delivery list sorted by route. Loading confirmation screen with barcode scan. Trip status updates.
Backend Mobile
WK 18
Delivery Confirmation EJBs
Delivery confirmation logic: full/partial delivery, returns with reason codes. Signature capture storage. Photo proof upload. GPS-tagged confirmation. Inventory update on delivery.
Mobile App: Delivery Confirmation Screen
Item-by-item delivery confirmation. Quantity adjustment (partial delivery). Return item with reason code selection. Signature pad capture. Camera for photo proof. GPS auto-capture.
Backend Mobile
WK 19
Trip Reconciliation & GPS Tracking
Trip completion: loaded vs delivered vs returned reconciliation. GPS tracking log aggregation. Trip summary report. AdminApp: real-time trip tracking view.
AdminApp: Loading Sheet & Delivery Tracking
Loading sheet print view. Real-time delivery tracking dashboard. Delivery status timeline. Return management. Trip reconciliation report.
Backend Frontend
WK 20
Phase 3 Integration & Testing
End-to-end: Order approved → Trip created → Loaded → Delivered → Confirmed. Delivery app field testing (GPS, camera, signature). Voucher generation testing (DN, LN). Bug fixes.
Demo & Stakeholder Review
Demo delivery workflow to TecCoop. Field test with sample delivery route. Feedback collection. Phase 4 planning.
QA PM
🏆
Milestone 3: Delivery & Logistics Live
Vehicle management, trip planning, delivery confirmation (signature + photo + GPS), route tracking, DN & Loading Note vouchers, delivery personnel mobile app

Phase 4: Financial

Invoicing, receipts, credit notes, payment collection, shop ledger, FinanceApp, CustomerPortal

6 Weeks
Weeks 21–26
WK 21
Invoice & Credit Note Vouchers
Voucher module completion: Invoice (INV), Receipt (REC), Credit Note (CN). Auto-generation on delivery confirmation. Tax calculation (voucher_tax_summary). Voucher status lifecycle: DRAFT → GENERATED → SENT → PAID.
Depends: P3 Voucher Module
FinanceApp: Project Setup & Dashboard
FinanceApp React project (Vite + Tailwind). Dashboard: revenue summary, outstanding receivables, payment collection trends (Recharts). Quick action cards.
Backend Frontend
WK 22
Payment Collection EJBs
JPA entities: payment, payment_allocation, daily_collection_summary. Payment methods: CASH, CHEQUE, BANK_TRANSFER, UPI, MOBILE_PAYMENT. Payment status lifecycle: COLLECTED → VERIFIED → DEPOSITED → CLEARED. Cheque bounce handling.
FinanceApp: Voucher Management
Invoice list with status filters. Invoice detail with line items & tax. Credit note creation (linked to parent invoice). Voucher PDF preview. Bulk send (email/WhatsApp).
Backend Frontend
WK 23
Shop Ledger & Payment Allocation
JPA entity: shop_ledger. DEBIT on invoice, CREDIT on payment. Running balance calculation. Auto-allocation of payments to oldest invoices. Credit limit enforcement. Overdue detection & notification trigger.
FinanceApp: Payment Management
Payment list with method & status filters. Payment verification workflow. Daily collection summary view. Cheque tracking & clearance. Payment receipt generation.
Backend Frontend
WK 24
JasperReports Templates
.jrxml templates: Invoice, Delivery Note, Receipt, Loading Note, Credit Note, Account Statement. PDF generation via @Asynchronous EJB. PDF storage & retrieval. Template customization per distributor.
FinanceApp: Shop Ledger & Reports
Shop ledger view: transaction history, running balance. Account statement generation. Aging report (30/60/90 days). Financial summary reports.
Backend Frontend
WK 25
CustomerPortal: Shop Owner & Vendor Views
CustomerPortal React project setup. Shop Owner: order history, invoice list, payment history, outstanding balance. Vendor: product performance, distributor orders, sales analytics.
Mobile App: Payment Collection
Outstanding invoices per shop. Multi-mode payment: Cash, Cheque (with photo), UPI, Bank Transfer. Receipt generation. GPS-tagged payment. Daily collection summary submission.
Frontend Mobile
WK 26
Phase 4 Integration & Testing
End-to-end financial flow: Delivery → Invoice → Payment → Receipt → Ledger update. JasperReports output validation. Payment reconciliation testing. Cheque bounce scenario testing. Bug fixes.
Demo & Stakeholder Review
Demo complete financial workflow to TecCoop. FinanceApp & CustomerPortal walkthrough. PDF voucher samples review. Phase 5 planning.
QA PM
🏆
Milestone 4: Financial Module Live
Complete invoicing, payment collection (multi-mode), shop ledger, JasperReports PDFs, FinanceApp, CustomerPortal, mobile payment collection

Phase 5: Analytics & Polish

Reports, dashboards, notifications, sync engine, dark mode, multi-language

4 Weeks
Weeks 27–30
WK 27
Report EJBs & Dashboard APIs
Sales reports: daily/weekly/monthly by rep, shop, product. Inventory reports: stock levels, movement, low stock. Delivery reports: trip efficiency, on-time rate. Financial reports: revenue, outstanding, aging. JasperReports integration for PDF/Excel export.
Depends: P4 Complete
AdminApp: Reports & Dashboards
Executive dashboard (Recharts): KPI cards, trend charts, top performers. Sales analytics. Inventory analytics. Delivery performance. Date range filters. Export to PDF/Excel.
Backend Frontend
WK 28
Notification EJBs
FCM push notifications (firebase-admin). Jakarta Mail 2.0.1 email. WhatsApp (Meta Cloud API). SMS gateway integration. Notification templates (Appendix C). User notification preferences. notification table for history.
Mobile App: Notifications & Daily Summary
Push notification handling. In-app notification center. Daily summary screen: orders placed, payments collected, shops visited. Notification preferences settings.
Backend Mobile
WK 29
Sync Engine & Audit Logging
Full sync engine: push (orders, payments, GPS) + pull (catalog, prices, routes). Conflict resolution: timestamp-based with server-side validation. Idempotency key deduplication. sync_log table. Comprehensive audit_log for all financial operations.
Mobile App: Offline Sync Engine
Background sync service. Sync queue management. Conflict resolution UI. Sync status indicator (online/offline/syncing/error). Data integrity validation. Retry with exponential backoff.
Backend Mobile
WK 30
UI Polish & Accessibility
All web apps: Dark mode toggle. Multi-language support (i18n — Sinhala, Tamil, English). Accessibility audit (WCAG 2.1). Performance optimization (lazy loading, code splitting). Mobile: dark mode, language selection.
Phase 5 Integration Testing
Notification delivery testing (all channels). Sync engine stress testing (100+ concurrent syncs). Report accuracy validation. Dark mode visual QA. Multi-language string review.
Frontend Mobile QA
🏆
Milestone 5: Feature Complete
All features implemented: reports, dashboards, notifications (FCM/Email/WhatsApp/SMS), offline sync engine, dark mode, multi-language. System is feature-complete.

Phase 6: Testing & Launch

Comprehensive testing, security audit, production deployment, user training, go-live

4 Weeks
Weeks 31–34
WK 31
Automated Test Suites
JUnit 5 + Mockito: 80% code coverage target. Integration tests for all API endpoints. Database migration tests. EJB business logic tests. Edge case & boundary testing.
Depends: P5 Feature Complete
Security Audit
OWASP Top 10 vulnerability scan. JWT token security review. SQL injection testing. XSS prevention validation. RBAC permission matrix verification. TLS 1.3 configuration audit.
QA Backend
WK 32
Performance & Load Testing
JMeter load tests: 500 concurrent users, 1000 req/sec target. Database query optimization. Redis cache tuning. API response time benchmarks (<200ms P95). Memory leak detection. MariaDB slow query analysis.
UAT — User Acceptance Testing
Field testing with real Sales Reps & Delivery Personnel. Admin users testing all web apps. Finance team testing voucher & payment flows. Bug tracking & prioritization. Feedback collection.
QA PM DevOps
WK 33
Production Deployment
Production server setup (Docker Compose). Nginx reverse proxy configuration (SSL termination). MariaDB production config (replication, backups). Redis production config. Monitoring setup (health checks, log aggregation). DNS & domain configuration.
App Store Submission
Android: Google Play Store submission (APK/AAB). iOS: Apple App Store submission (TestFlight → Review). App store assets: screenshots, descriptions, privacy policy. OTA update mechanism setup.
DevOps Mobile
WK 34
User Training & Documentation
Training materials: Admin guide, Finance guide, Sales Rep guide, Delivery guide. Video tutorials for mobile app. FAQ documentation. Troubleshooting guide. API documentation (Swagger).
Go-Live & Handover
Phased rollout: pilot with 2-3 distributors → full rollout. Data migration (if applicable). Go-live monitoring (24/7 for first week). Handover documentation. Support SLA agreement. Post-launch review meeting.
PM QA DevOps
🎉
Milestone 6: PRODUCTION GO-LIVE
System deployed to production. Mobile apps on App Store & Play Store. Users trained. Pilot distributors onboarded. 24/7 monitoring active. Project handover complete.
