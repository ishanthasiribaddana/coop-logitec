Infrastructure & Database

🗂

MariaDB 10.6

Relational database. Shared schema mvdsms_system. JDBC 3.x / MySQL Connector 8.0.

⚡

Redis 5.0.2

In-memory cache via Jedis client. Session management, frequently accessed data, generated PDF caching.

📦

Docker Compose

Containerized deployment. WildFly + MariaDB + Redis + 3 React apps. Nginx reverse proxy with SSL.

🔌 Offline Capabilities

  • ✓ Order collection works fully offline
  • ✓ Delivery confirmation with signature & photo
  • ✓ Payment recording offline
  • ✓ GPS coordinates captured and queued
  • ✓ Product catalog cached locally
  • ✓ Sync queue persists across app restarts

🔄 Sync & Conflict Resolution

  • ✓ Auto-sync when connectivity restored
  • ✓ UUID idempotency keys prevent duplicates
  • ✓ Timestamp-based last-write-wins strategy
  • ✓ Server-side inventory re-validation
  • ✓ Conflict log for manual resolution
  • ✓ sync_log table for audit trail
