Module 7

📋 Voucher Module (DN, Invoice, Receipt, Credit Note)

Unified voucher system with auto-generated PDFs via JasperReports

📄 Delivery Note (DN)

Auto-generated when goods loaded onto vehicle. Contains itemized product list, shop details, order reference. Printable PDF.

💵 Invoice (INV)

Auto-generated upon delivery confirmation. Tax calculation (GST/VAT), credit terms, payment tracking. Status: Generated → Sent → Paid/Overdue.

🧾 Receipt (REC)

Generated on payment collection. Links to invoice via payment_allocation. Printable and digital format.

🔄 Credit Note (CN)

Issued for returns and adjustments. References parent invoice. Auto-posts to shop_ledger as CREDIT entry.

🚚 Loading Note (DN_LOAD)

Consolidated loading sheet per vehicle. Lists all products across all orders for a delivery trip.

📋 GRN Voucher (GRN_V)

Goods Received Note voucher for stock-in from vendors. Links to goods_received_note records.
